## 香港云服务器真正该看什么？

先别被“香港”两个字带跑偏。

香港节点的优势很直观：距离中国大陆近，而且面向香港本地或亚太业务时，网络路径通常比美西这类节点更短。近期多篇香港 VPS 选购文章都把“线路质量”和“晚高峰表现”放在硬件配置之前，因为同样是香港机房，普通国际线路、CN2 优化线路、CMI 或多线 BGP 的实际体验可能差很多。

对于面向大陆用户的网站，至少要看四个参数：

**第一是线路。**
“香港机房”只是地理位置，不等于一定有优质回程。LisaHost 的三网直连产品页明确写出电信去程 CN2、联通去程 9929、移动去程 CMI，并将产品定位在大陆三网访问、建站和网络中转等场景。

**第二是带宽。**
100Mbps 和 3000GB 流量不是一回事。前者更接近实时传输能力，后者是月度用量上限。做动态网站、API、后台管理时，带宽和延迟更容易成为瓶颈；做图片、文件、视频分发时，月流量又会变得非常重要。

**第三是流量规则。**
“3TB”很好理解，“不限流量”却要继续看带宽是多少。LisaHost 当前香港三个产品组里，确实同时存在按月流量套餐和不限流量套餐，价格跨度从几十元级别一路到近两千元/月。

**第四是 IP 属性。**
如果你只是跑网站、博客或 API，普通公网 IPv4 往往就够；如果你的需求与香港本地服务、住宅 IP、流媒体或某些需要本地网络身份的场景相关，那么 HGC、iCable 这种产品和普通三网线路 VPS 就不是一回事。LisaHost 官方当前页面把 HGC 和 iCable 都单独做成了住宅 IP 产品组。

> **一个很实用的判断方法：先回答“我的用户在哪”，再回答“我需要多大配置”。**
> 访客主要在中国大陆、香港和周边亚洲地区，与主要服务北美用户的项目，适合的机房逻辑本来就不同。近期选购指南也普遍把“用户所在地”放在线路和价格之前。

这里特别容易误会。

所以“不限流量”更适合这些情况：

## 香港云服务器“推荐”文章里经常漏掉的几个坑

### 香港近，不代表你的晚高峰一定快

近期多篇香港 VPS 指南都提醒这一点。线路比地理位置名称更重要，同样是香港节点，普通国际线路与 CN2、CMI 或多线优化线路可能出现非常不同的晚高峰表现。

所以正式业务上线前，建议至少做一次：

bash
ping -c 100 <服务器IP>


再用：

bash
mtr -rwz <服务器IP>


看路径和丢包情况。最好在晚上再次测试，而不是只在下午测试一次。16IDC、VPSCost 等近期选购文章都把晚高峰测试列为重要步骤。

### 端口速度不是长期保底吞吐
